# AI-Assisted Project Monitoring & Decision Support

This is an **independent synthetic demonstration**, not an enterprise deployment or verified AI improvement. It extends the supplier requirements workflow with a separate, deterministic project-monitoring scenario.

Run `python -m extensions.project_monitoring`. Requires only Python 3.10+.

The four invented tasks include due-date offsets, progress, blockers and criticality. Transparent rules flag overdue tasks and critical blocked tasks for human review; the script does not autonomously change project plans or approve anything. These rules are **not a trained AI model**. They provide a testable baseline for a future AI-assisted project management study.

## Proposed research design
Compare deterministic baseline with a separately developed LLM recommendation module using pre-registered risk labels and blind human adjudication. Measure precision, recall, reviewer agreement, false-positive rate and decision time. Interview PMO stakeholders about explainability, governance and change management. Do not claim productivity gains before a real evaluation.

## Application relevance
Project governance, risk triage, workflow transparency and decision support for Toyota-style AI-in-project-management thesis proposals.
